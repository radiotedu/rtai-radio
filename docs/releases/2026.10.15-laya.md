# v2026.10.15-laya

The pinned Laya package remains 0.3.22 and model revision remains
`e4e9ddf21a7b1903b7acffd8814ad4307bf63a67`.

## Changes

- Reuse locally admitted title, artist and duration facts only while file size and nanosecond modification time match the original verified record. Changed or missing entries follow normal Mutagen admission. The optional cache contains no song choices or probabilities.
- Avoid repeated full media opens during startup, catalog refresh and live candidate metadata lookup. A staged admission of 1,752 real downloaded AI tracks took EN 3.406 seconds and FR 3.203 seconds, with zero skipped metadata records.
- Add an optional public-catalog staging collector. It preserves original identity, AI disclosure, source URL, observed play count, commercial grant URL and file SHA-256, and screens lyrics/language and full-track length. Optional collection dependencies include BeautifulSoup, Mutagen and langdetect. It never edits live playback roots or publishes selection events.
- Include a public factual catalog index with 1,752 AI-disclosed recordings. Music binaries, private local paths, credentials, outboxes and operator configuration are excluded.

## Catalog provenance

The catalog contains 480 Pop, 292 Electronic, 252 Rock, 251 Folk, 194 Jazz,
188 Hip-Hop, 66 Lo-Fi and 29 Classical tracks. Publisher-disclosed AI music
uses the [Star Singer public commercial-use grant](https://starsinger.ai/free-music-for-youtube);
the classical subset uses the explicitly AI-generated [CC0 collection](https://archive.org/details/ai-early-romantic).
Original copyright notices are retained. AI generation alone does not establish a license.
Observed play counts are preserved; this is not a claim that all recordings are popular hits
or have received a human listening review.

## Admission cache

`audio_admission_cache.cache_path()` defaults to the RadioTEDU cache directory
under PROGRAMDATA (or the user's local share directory on other systems).
An explicit `RADIOTEDU_AUDIO_ADMISSION_CACHE` can select another operator cache.
Version 1 has a `records` object keyed by case-folded absolute path. Each
record holds `bytes`, `verified_mtime_ns`, `sha256`, `duration_seconds`,
`title` and `artist`, obtained from original verified media, plus optional provenance.
Do not populate it from invented metadata or fabricate MusicBrainz IDs.
Normal broadcast metadata safety checks still apply. A MusicBrainz requirement,
if enabled by an operator, is not bypassed by this cache.

## Runtime evidence

Both English and French sources were observed sending new-catalog audio with
four future songs in each Laya queue. Fresh rolling choices continue through
the normal model and durable delivery worker. Existing announcement loudness,
Kokoro completion gating, model pin and single-choice evidence schema remain in effect.
No unit test suite was run for this release; the admission timings and runtime
observations above are operational evidence. Listener continuity remains a separate dependency.
